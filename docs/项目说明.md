# 项目说明：团队协作分工智能体（昇腾全模态版）

> 更新时间：2026-08-24
> 用途：创新应用赛道提交材料之一。对应评审点：创新性、实用性、工程完整度、
> 可运行可展示、统一昇腾环境复现。

## 1. 一句话介绍

把项目要求、成员能力、截止日期转化为可编辑的任务拆解、分工、排期和报告，
并以 MiniCPM-o 4.5 的全模态能力（文本 / 语音 / 图片 / 视频 / TTS）作为核心输入接口，
形成「拍照立项 → 说话排期 → 确认分工 → 语音/照片汇报 → 群通知」的协作闭环。

## 2. 解决的问题

- 普通规划工具只在项目开始时生成一张静态计划表，项目一变就过时；
- 多模态大模型常被当作"聊天机器人"附加功能，没有进入真实协作流程；
- 成员更新任务状态成本高，负责人反复追问进度；
- 会议/讨论的内容（录音、录像、白板照片）需要人二次整理才能变成任务。

## 3. 系统架构

```text
┌────────────────────────────────────────────────────────────┐
│ 前端（工作台 + 成员轻量汇报页）                                │
│ 文本 / 语音 / 拍照 / 录像 / TTS / 甘特图 / 导出 / 提醒         │
└───────────────┬────────────────────────────────────────────┘
                │ HTTP / WebSocket
┌───────────────▼────────────────────────────────────────────┐
│ FastAPI 后端（/api）                                        │
│ 计划引擎：拆解 → 校验 → 分工 → CPM 关键路径排期 → 报告          │
│ 多模态适配：omni_chat（本地直听 / 云端先转写再理解）            │
│ 媒体分析：PyAV 抽帧/抽音频、图片理解、扫描 PDF、音频转写         │
│ 协作闭环：汇报 token、负责人确认制、重算、Webhook 通知          │
└───────┬───────────────────────────────────┬────────────────┘
        │ WebSocket /backend                │ WebSocket wss://api.modelbest.cn
┌───────▼──────────────┐          ┌─────────▼──────────────────┐
│ 昇腾 A3（910C）       │          │ 云端 ModelBest Realtime API │
│ llama.cpp-omni       │          │ MiniCPM-o-4.5-Realtime     │
│ MiniCPM-o-4_5-F16    │          │（免费 API，开发期兜底）      │
└──────────────────────┘          └────────────────────────────┘
```

关键设计：

- **两种后端一键切换**：`ASCEND_OMNI_WS_URL` 指向 A3 即走本地昇腾；
  注释掉走云端免费 API。`/api/realtime/status` 返回 `backend: local|map` 直观确认。
- **音频理解统一入口** `app/services/omni_chat.py`：本地能直接听；
  云端 turn-based 表现为"转写并复述"，自动改为先转写再文字理解。
- **边看边听**：答辩录像、会议录像统一「抽帧（均匀采样，流式不整段载入）+ 抽音频」，
  画面与声音分别理解后合并输出。
- **计划引擎确定性兜底**：LLM 不可用时任务拆解、分工、时间线均有确定性算法兜底，
  演示不依赖模型持续在线。

## 4. 核心能力与演示闭环

| 环节 | 能力 | 说明 |
|---|---|---|
| 拍照立项 | 📷 拍照需求 | 白板/截图/手绘直接进文件分析；无文字流程图也能理解（不止 OCR） |
| 说话排期 | 🎤 语音需求 / 语音对话 | 录音进需求材料或直接对话；会议录音/录像边看边听整理任务 |
| 确认 | 草案可编辑 + 确认分工 | 人机协同：AI 建议、人做判断、改动自动重算 |
| 汇报 | 成员汇报链接 | token 绑定 方案+成员，无需登录；🎤 语音汇报 / 📷 拍照交付 |
| 触达 | 群通知 / 今日播报 | 状态变更自动推送 Webhook；云端 TTS 播报今日要点 |
| 答辩 | 语音/视频直接对话 | 评委听（看）后点评追问；视频附逐帧表现观察 |

## 6. 接口清单（核心）

### Realtime / 多模态

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/realtime/chat` | 文本多轮对话（带方案快照） |
| POST | `/api/realtime/voice-chat` | 直接语音对话（返回文本 + 可选 TTS WAV） |
| POST | `/api/realtime/transcribe` | 录音转写（填输入框/需求用） |
| POST | `/api/realtime/tts` | 文本朗读（仅云端；本地 501） |
| POST | `/api/realtime/interview-turn` | 答辩语音/视频直接对话（摘要 + 评委回复 + 表现观察） |
| POST | `/api/realtime/meeting` | 会议旁听：录音/录像边看边听 → 要点/任务/风险 + 画面理解 |
| POST | `/api/realtime/performance` | 答辩录像表现分析 |
| GET | `/api/realtime/status` | 后端状态（local/map） |
| POST | `/api/analyze-files` | 多模态文件分析（图片/音频/PDF/PPTX 等） |

### 计划与协作

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/draft` / `/api/confirm-draft` | 拆解草案 / 确认 |
| POST | `/api/run` / `/api/edit` / `/api/recompute` | 完整计划 / 编辑 / 重算 |
| POST | `/api/save` / `/api/plans` | 保存 / 列出方案 |
| POST | `/api/report/link` | 生成成员汇报链接 |
| GET | `/api/report/state` | 我的任务 |
| POST | `/api/report/voice` / `photo` / `update` | 语音汇报 / 拍照交付 / 应用变更 |
| POST | `/api/reminders` / `/api/notify` | 提醒 / 通知推送 |

导出：`/api/docx`、`/api/pdf`、`/api/markdown`、`/api/excel`、`/api/csv`、`/api/ics`。

## 7. 复现步骤（摘要）

完整命令见 [复现文档.md](./复现文档.md) 与
[昇腾A3_910C_llama_omni部署指南.md](./昇腾A3_910C_llama_omni部署指南.md)。

```bash
# 3) 演示前预检（含暖机）
python scripts/preflight_demo.py
```

## 8. 测试与验证结果

- 全量自动化测试：`python -m pytest tests/ -q` → 352 passed（无需配置密钥）
- 昇腾 A3 实测（910C / CANN 9.1.0-beta.1 / llama.cpp-omni / F16）：
  - 文本对话 ~2s 返回；语音理解 ~8s；图片理解 ~7s（含无文字流程图）；
  - 答辩录像 4 帧表情分析 4s；会议视频边看边听端到端 16s（3 帧 + 音频理解）；
  - 健康检查 `{"engine":"comni","status":"ok"}`。
- 云端 API 实测：语音转写、图片理解、TTS 朗读均正常；音频理解自动「先转写再理解」。

## 10. 已知边界（如实说明）

- 8B 模型推理能力有限，演示主打感知与流程闭环，不做高难度推理；
- 910C 本地 TTS 有已知算子问题，语音播报走云端 API；
- 云端 turn-based 音频表现为转写，已通过适配层统一行为；
- `llama-omni-server` 同一时间只支持一个活跃 session，演示前跑预检暖机。
