# 多模态落地改造清单（全模态 × 分工协作）

> 更新时间：2026-08-21
> 主线：把多模态从"AI 建议抽屉"这个角落，变成核心协作流程的输入接口，形成闭环——
> **多模态输入 → 计划引擎 → 状态更新 → 通知触达**。

## 已完成（v6.8）

- ✅ 前端 AI 建议抽屉接通 MiniCPM-o Realtime，对话自动附带当前方案快照
- ✅ 抽屉 🎤 直接语音对话：录音直接发 MiniCPM-o 理解并回答（本地文字回答，云端可语音回复）；配置页 🎤 添加语音需求：录音作为需求材料进文件列表（与拍照同理）
- ✅ TTS 语音回复（仅云端；本地昇腾自动禁用 + 失败降级纯文本）
- ✅ 三级媒体兜底链路（MiniCPM-o → 阿里 DashScope → 元数据），兜底默认注释以暴露昇腾故障
- ✅ 本地昇腾真实验证：文本对话 2s、语音转写 8s、图片理解 7s（含无文字流程图）

## P0：需求输入升级（全模态进入核心流程的第一步）

### 1. 语音 / 拍照直接生成任务（✅ 已完成 v6.9）

- **改什么：** 项目配置页"上传任务要求文件"旁增加 🎤 添加语音需求和 📷 拍照需求入口
- **模态：** 语音转写 + 图片 OCR/理解
- **复用：** `/api/realtime/transcribe`、`/api/analyze-files`、`/api/draft`
- **交互：** 说"我们三个人五天完成一个调研报告"→ 文本自动填入背景 → 直接生成草案；拍白板/微信群需求截图 → OCR 后同样进拆解
- **验收：** 全程不打字，只说话或拍照能生成一份可编辑草案
- **工作量：** 1 天（已实现；A3 恢复后按验证清单复核端到端）

## P1：执行期闭环（落地实用性的核心）

### 2. 轻量汇报页（成员端）（✅ 已完成）

  - 成员专属 token 链接（绑定 方案+成员，14 天有效）→ 我的任务列表
  - 🎤 语音汇报：AI 听懂动作（状态/工时/备注）→ 确认应用
  - 📷 拍照交付：上传照片自动标记完成
  - 状态变更自动重算 + 保存 + 推送到外部 Webhook
  - 已完成

### 3. 通知触达：群机器人（✅ 已完成）

  - `APP_NOTIFY_WEBHOOK` 接群机器人；汇报页状态变更自动推送事件
  - 提醒页保留手动"发送提醒通知"（webhook 或浏览器通知）
  - 已完成

### 4. TTS 提醒播报（✅ 已完成）

  - 提醒页"🔊 今日播报"：云端 TTS 语音播报今日要点，本地降级文字
  - 已完成

### 5. 会议旁听（✅ 已完成）

  - 配置页"🎙 会议旁听"：上传录音 → MiniCPM-o 整理 要点/任务（负责人/截止）/风险
  - "生成任务草案"自动填入背景并进入拆解
  - 已完成

## P2：体验与加分

### 6. 视频理解

- **改什么：** 录一段项目讨论/演示视频 → 抽帧 + 抽音频 → 边看边听总结任务
- **模态：** 视频 + 音频 + 视觉（MiniCPM-o 最独特能力）
- **注意：** A3 视觉已验证可用；视频链路先按 omni_mode 抽帧发云端/A3 验证
- **工作量：** 2-3 天

### 7. 移动端适配

- **改什么：** 汇报页 + 工作台移动端录音/拍照可用
- **工作量：** 1 天

### 8. 答辩模拟语音/视频直接对话（✅ 已完成）

- **改什么：** 🎤 语音回答、📹 视频回答均为"直接对话"：音频/画面直接发给评委，评委听完/看完当场点评追问；视频附表现观察；文本回答保留；无材料/无关注点时基于项目方案提问
- **工作量：** 已完成（含语音播报）

### 9. 演示脚本改造

- **改什么：** 五步演示改为多模态驱动：拍照 → 说话 → 确认 → 执行汇报 → 群通知提醒
- **工作量：** 0.5 天

## 比赛材料（与功能并行）

- PPT：系统架构图 + 全模态场景截图 + 与纯聊天助手的差异点
- 演示视频：昇腾录屏（文本对话 / 语音输入 / 图片 OCR）+ 云端 TTS 段落
- 项目说明 + 复现文档 + 故障兜底说明
- 复用现有：`docs/功能验证清单.md`、`docs/比赛全量备赛手册.md`

## 红线（演示必守）

- 本地昇腾不开 TTS（910C 算子问题，会挂服务）；语音回复只走云端
- 兜底配置默认注释，避免昇腾故障被静默掩盖
- 不问模型身份（MiniCPM-o 会自称通义千问等）
- 8B 模型推理弱，演示主打感知与流程，不做高难度推理
