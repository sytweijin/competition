# 网页端演示流程

## 准备

1. 打开工作台页面，清空无关历史方案。
2. 准备一份课程要求 PDF、一张图片和一份音频（可选）。
3. 确认浏览器允许下载文件。

## 主流程

### 1. 读文件

- 点击“上传任务要求文件”，选择 PDF/Word/PPT/Excel/图片。
- 文件列表应逐项显示状态：已读取、需要确认、无法识别或超过限制。
- 对无法识别的文件，现场解释“系统不会静默跳过，会明确告诉你需要人工确认”。

### 2. 生成与决策

- 点击“AI 生成任务拆解”，等待草案。
- 确认拆解并开始分工，进入最终方案。
- 讲解首屏：总工期、截止缓冲、健康度、分工概览、关键任务。

### 3. 发现风险

- 打开“方案评审”或“项目报告”，指出 1-2 条证据化风险。
- 话术示例：“当前最高负载成员占用 90% 可用工时，风险来自 T3 技能匹配度偏低。”

### 4. 应对变化

- 在 AI 调整区输入“如果小林请假两天”，查看推演候选。
- 回复“确认应用”，对比变化摘要、负载变化和截止日期影响。
- 打开版本树，展示这次修改已进入同一版本族。

### 5. 交付

- 打开甘特图，逐行核对任务编号、负责人、工时和前置任务。
- 导出 Markdown、Word、PDF 或 Excel。

## 验收

- [ ] 文件状态逐项可见；
- [ ] 决策摘要优先于完整计划；
- [ ] 风险都能回到结构化字段解释；
- [ ] 推演确认后版本树新增节点；
- [ ] 至少成功导出两种格式。
