## 2. 比赛总览

- 主办：OpenBMB / 面壁智能、华为昇思 MindSpore、昇腾生态。
- 主题：围绕 `MiniCPM-o 4.5` 全模态模型，在昇腾 NPU 上做推理、应用落地。
- 奖金：总奖金 406,000 元，两个赛道分别设奖，共 12 位获奖者。
- 队伍：个人或不超过 3 人团队。
- 算力：赛事提供昇腾开发者线上算力，公开说明为 100 卡时起、多用多得。
- 公开赛事页显示的截止时间约 2026-09-04，另一赛事页显示 09-13，最终以官方群/官网公告为准。

## 3. 创新应用赛道要求

赛道定位：基于 MiniCPM-o 4.5 的全模态能力，把想法构建成可运行、可展示、可体验的 Demo。

鼓励方向：

- 实时问答
- 伴随式助手
- 视觉 / 语音交互
- 端侧应用
- 多模态场景理解
- 教育、办公、创作、生活服务等应用场景

评审重点：

- 全模态能力的产品化表达
- 交互体验
- 工程完整度
- 可运行、可验证、可展示
- 统一昇腾环境下的复现验证

## 4. 你的项目现状

项目定位：协作分工智能体，把项目要求、成员能力、截止日期转化为可编辑的任务拆解、分工、排期和报告。

已接入 MiniCPM-o Realtime 的能力：

- 文本：`POST /api/realtime/chat`
- 图片 OCR：上传图片 / 扫描 PDF 自动走 MiniCPM-o Realtime
- 音频转写：上传 mp3/wav/m4a/webm 自动走 MiniCPM-o Realtime
- TTS：接口已支持返回音频 Base64，前端播放尚未完成
- 本地昇腾后端：配置 `ASCEND_OMNI_WS_URL` 后，对话链路直接走 A3 的 `llama-omni-server /backend`

关键文件：

- `app/services/realtime_client.py`：Realtime 协议客户端
- `app/services/media_analysis.py`：图片 OCR / 音频转写
- `app/web/routers/realtime.py`：对话与状态接口
- `docs/华为昇腾创新应用赛道接入说明.md`：接入说明

## 7. A3 一直申请不下来怎么办

优先级：

1. 继续申请 A3，但不要卡住整体进度；开发期先走 API。
2. 申请 A2 作为保底环境，先验证 CANN 9.1.0-beta.1 + llama.cpp-omni 能否启动。
3. 在群里问是否有共享环境、固定开机时间段或 A2 可用的模型配置。
4. 每天固定时间抢算力，用完及时释放；演示脚本要短，避免浪费卡时。
5. 最坏情况下用云端 API 录制 Demo 并明确标注，但这会降低“昇腾环境复现”得分，只能作为兜底。

## 8. 提升竞争力的路线

### 8.1 实时双工（最高优先级）

把当前 turn-based 对话升级为实时语音/视频双工体验：

- 用 `mode=audio` 或 `mode=video` 接入连续音频/视频帧。
- 前端支持按住说话、实时字幕、TTS 语音回复。
- 这是 MiniCPM-o 4.5 相对普通多模态模型最突出的能力，也是比赛最想看到的“边看边听主动说”。

### 8.2 视频理解

- 增加视频上传/摄像头输入。
- 用 PyAV 抽帧 + 抽音频，按 `omni_mode: true` 发给 Realtime API。
- 场景示例：用户拍一段项目现场或团队讨论，AI 边看边总结并输出任务。

### 8.3 产品化场景

把 Demo 包装成一个有说服力的完整场景，例如“团队协作全模态助理”：

- 上传课程要求图片/音频 → MiniCPM 自动识别 → 生成任务拆解。
- 团队成员用语音提问 → MiniCPM 基于当前方案回答 → 语音回复。
- 摄像头/视频输入 → AI 实时理解现场材料 → 更新任务或给出建议。
- 保留原工作台的甘特图、分工、报告和导出，体现工程完整度。

### 8.4 工程与体验

- 前端增加 TTS 播放和音频录制。
- 对话流式展示，减少等待感。
- 所有多模态失败都有清晰提示和回退。
- 整理启动脚本、`.env.example`、README、演示流程，保证复现。

## 9. 最终提交材料

创新应用赛道至少需要：

1. 可运行 Demo / Web Demo / App（含源码仓库、部署和启动说明）。
2. PPT：项目背景、场景、技术架构、创新点、全模态演示截图。
3. 项目说明：架构、模块、API、复现步骤、测试结果。
4. 演示视频：完整展示文本、图片、语音、TTS，最好在昇腾环境录屏。
5. 建议附上：系统架构图、接口文档、健康检查、性能/延迟记录、故障兜底说明。
