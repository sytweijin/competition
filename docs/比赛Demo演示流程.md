# 比赛 Demo 演示流程

> 更新时间：2026-08-22
> **主推：多模态驱动五步演示**（拍照 → 说话 → 确认 → 汇报 → 群通知），
> 详见 [演示脚本.md](./演示脚本.md)。本文件保留六步文字版作为降级/补充素材。

## 五步黄金演示（推荐）

核心主张：普通工具只在项目开始时生成一张计划表；系统在项目持续变化时，帮助团队不断做出更好的协作决策。

1. **读文件**：上传课程要求 PDF/Word/PPT/图片，回答中逐文件显示“已读取 / 需要确认 / 无法识别”状态。
2. **做决策**：首屏先给决策摘要：项目规模、截止缓冲、分工概览、关键任务；完整计划按需展开。
3. **发现风险**：展开健康度与证据化风险，指出截止缓冲不足、技能匹配低或负载偏高的任务。
4. **应对变化**：现场说“如果小林请假两天”“把截止日期提前 3 天”或“新增一个演示视频”，展示推演候选，再回复“确认应用”。
5. **交付成果**：返回可视化工作台，展开甘特图并导出 PDF/Word/Excel，强调版本树记录每一次修改。

网页端、移动端和故障兜底三套详细流程见：

- [网页端演示](docs/演示流程-网页端.md)
- [移动端演示](docs/演示流程-移动端.md)
- [故障兜底演示](docs/演示流程-故障兜底.md)

## 演示目标

用 4–6 分钟完整展示：

`项目输入 → 任务拆解 → 人工调整 → 智能分工 → 甘特图 → 导出`

主案例使用“校园低碳生活倡议发布”。它同时包含调研、文案、设计、活动执行和复盘，能直观展示任务依赖、技能匹配、负载均衡和时间缓冲。

## 演示前准备

1. 启动服务并打开工作台。
2. 确认浏览器下载权限正常。
3. 如现场网络或模型不稳定，使用快速草案兜底；完整流程不依赖模型持续在线。
4. 演示前清理无关历史方案，只保留一份备用结果。

## 标准讲解脚本

### 1. 项目输入（约 30 秒）

点击“载入演示案例”。

讲解重点：

- 项目不仅输入标题，还包含背景、交付物、起止日期和成员能力。
- 成员可用产能按照实际项目天数计算，不再固定按 30 天估算。
- 技能标签支持“文案写作/报告撰写”“PPT/幻灯片”等近义表达。

### 2. 任务拆解（约 60 秒）

点击“生成任务拆解”，展示任务名称、说明、工时、建议人数、阶段、技能和依赖。

讲解重点：

- 先拆任务、不急着分人，避免“任务尚未确认就直接生成静态分工表”。
- 每项任务都能编辑，工时和依赖关系透明。
- AI 不可用时仍能用确定性方案继续演示。

### 3. 人工调整（约 45 秒）

演示以下任意两项：

- 把某项任务工时增加 1 小时；
- 拖动一项任务改变顺序；
- 拆分一项较大的任务；
- 修改所需技能或执行阶段。

讲解重点：人负责做最终判断，系统负责校验依赖与数据一致性。

### 4. 智能分工（约 60 秒）

点击“确认拆解并开始分工”，展示成员看板、工作量和技能匹配。

讲解重点：

- 分配同时考虑技能、现有负载、阶段负载和可用产能。
- 单人任务不再强制塞满多个协作者；建议人数决定协作规模。
- 可以拖拽任务或修改负责人，系统立即重新计算工作量。

建议现场把一项视觉任务拖给文案成员，再恢复自动分工，对比说明“系统建议可解释，但用户始终有最终控制权”。

### 5. 甘特图（约 60 秒）

确认最终分工后打开“时间线 / 甘特图”。

颜色说明：

- 红色：关键路径，延误会影响整体截止时间；
- 黄色：缓冲较少，应重点关注；
- 绿色：缓冲充裕，可灵活调整；
- 紫色：任务阻塞，需要干预。

排期明细会直接显示每项任务的日期和浮动时间，不再使用含义不明的装饰色条。

### 6. 导出（约 30 秒）

在最终方案右上角依次指出 Markdown、Word、PDF 三种导出按钮，并现场导出一种格式。

收尾话术：

> 这不是一次性生成的静态分工表，而是一套允许人持续调整、并能自动重算人员与排期的协作方案。

## 现场异常兜底

- 模型超时：说明系统已自动使用确定性任务蓝图，继续后续步骤。
- 输出不够理想：在任务拆解页人工改一项任务，强调人机协同。
- 下载被浏览器拦截：改为展示最终报告页，并说明三种导出接口均已验证。
- 时间不足：跳过历史方案和状态更新，只演示主链路六步。

## 验收检查

- [ ] 演示案例可一键填充；
- [ ] 任务拆解可增、删、改、拆分、合并、排序；
- [ ] 确认后能生成负责人和工作量；
- [ ] 手动调整负责人后可确认；
- [ ] 甘特图具备四色图例和明确排期明细；
- [ ] Markdown、Word、PDF 至少各成功导出一次；
- [ ] 历史方案可保存、载入和删除。
