# 功能验证清单（P0 全模态交互）

> 更新时间：2026-08-22
> 范围：v6.8 的前端 MiniCPM-o 对话、语音输入、TTS、兜底与文件多模态链路。

## 1. 自动化验证（随时可重跑）

先启动服务：

```bash
python -m app.main
```

### 0. 演示前一键预检（推荐每次演示前先跑）

```bash
python scripts/preflight_demo.py
```

检查：应用服务（版本号）、当前后端（本地昇腾/云端）、A3 health、Realtime 状态、MiniCPM-o 真实对话暖机。全部通过输出"可以开始演示"；有 ❌ 项时退出码为 1，并附修复提示。

### 1.1 状态与配置

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/realtime/status
```

预期：`enabled: true`，`backend: "local"`（昇腾）或 `"map"`（云端）。

### 1.2 Realtime 对话（带计划上下文）

```powershell
$body = @{ messages = @(
  @{ role = "user"; content = "【当前方案快照】`n项目：校园低碳生活倡议发布`n任务 5 项，总工时 45h`n  T1 调研（8h，张三）`n  T2 文案（6h，李四）`n  T3 设计（10h，王五）" },
  @{ role = "assistant"; content = "好的，我已了解当前方案。" },
  @{ role = "user"; content = "谁的负担最重？" }
); max_new_tokens = 300 } | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/realtime/chat -Method Post -ContentType "application/json" -Body $body
```

预期：返回 `backend: "local"`，回答基于快照内容（如"王五 10 小时最重"），不是通用闲聊。

### 1.3 语音转写

用系统 TTS 生成一段真实语音（PowerShell）：

```powershell
Add-Type -AssemblyName System.Speech
$s = New-Object System.Speech.Synthesis.SpeechSynthesizer
$s.SelectVoice("Microsoft Huihui Desktop")
$s.SetOutputToWaveFile("$env:TEMP\test_speech.wav")
$s.Speak("今天下午三点开组会，调研报告下周一提交")
$s.Dispose()
```

再上传转写：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/realtime/transcribe -Method Post -Form @{ file = Get-Item "$env:TEMP\test_speech.wav" }
```

预期：`source: "realtime"`，`text` 包含"组会/调研报告/下周一"等关键内容（模型可能附带思考过程文字，属正常现象）。

### 1.4 图片理解（昇腾本地视觉，含无文字图片）

用 PIL 生成带中文文字的图片，上传：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/analyze-files -Method Post -Form @{ files = Get-Item "测试图片.png"; background = "测试" }
```

预期：文件状态 `ok`，分析摘要含图片中的文字。

### 1.5 兜底链路

直连 `/api/chat`（通用模型）应正常返回；把 `ASCEND_OMNI_WS_URL` 注释掉后，页面聊天应提示"已切换通用模型"并继续回答。

### 1.6 阿里 DashScope 媒体兜底

> 当前 `.env` 中 `APP_VISION_*` / `APP_ASR_*` 默认注释（让昇腾故障可见）。要验证本项，先取消 `.env` 中这 9 行注释并重启，再屏蔽 MiniCPM-o（临时把 `MAP_REALTIME_API_KEY`、`ASCEND_OMNI_WS_URL` 置空），然后上传图片和录音：

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/analyze-files -Method Post -Form @{ files = Get-Item "图片.png"; background = "测试" }
```

预期：文件状态 `ok`，摘要含图片文字；`/api/realtime/transcribe` 同样能返回转写文本（`source: "asr"`）。

验证完记得恢复注释，避免兜底模型静默掩盖昇腾故障。

## 4. 演示红线

- 本地昇腾后端绝不打开"语音回复"（TTS 只用于云端演示）；误开会导致 llama-omni-server 挂起，需在 A3 上 `pkill -f llama-omni-server` 后重启。
- 不要问模型"你是谁/基于什么模型"——MiniCPM-o 会自称通义千问等，属已知现象。
- 语音转写可能附带思考过程文字，演示时先展示"识别后可编辑"这个交互，再点发送。
