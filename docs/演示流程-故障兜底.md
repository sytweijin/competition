# 故障兜底演示流程

## 原则

主链路永不中断：LLM 失败时使用确定性兜底，文件失败时明确提示，模型恢复后仍能继续。

## 常见故障与话术

### 模型超时

- 现象：生成任务拆解等待超过 40 秒或返回“AI 响应超时”。
- 应对：点击“快速生成”，或解释“系统已自动使用确定性任务蓝图继续演示”。
- 话术：“主链路不依赖模型持续在线；模型恢复后可以继续追问同一份方案。”

### 文件无法识别

- 现象：状态标签显示“无法识别”或“需要确认”。
- 应对：直接展示标签，说明系统不会伪造读取结果。
- 话术：“这份文件没有提取到可分析文字，需要人工确认；这是刻意的透明设计。”

### 下载被浏览器拦截

- 应对：改为打开最终报告页，展示 Markdown/Word/PDF/Excel 导出按钮。
- 话术：“导出接口已经过自动化验证，现场可以用报告页继续讲。”

### 分享链接过期或已撤销

- 应对：重新生成一份工作台链接，或用原 token 重新打开。
- 话术：“编辑链接有时效、可撤销，过期后会明确提示，不会静默访问旧版本。”

### 服务重启

- 本地或对象存储同步后，方案 JSON 应能恢复。
- 自动演练命令：

```bash
python scripts/fault_drills.py
```

- 演练记录写入 `docs/drill-records/`。

## 验收

- [ ] 快速生成可在无模型时完成全流程；
- [ ] 文件失败状态对用户可见；
- [ ] 下载拦截有替代路径；
- [ ] 服务重启后方案仍在；
- [ ] 每次评审前重新运行 `scripts/fault_drills.py` 并保留记录。
