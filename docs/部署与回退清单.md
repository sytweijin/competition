# 部署与回退清单

> 用于比赛评审期锁定依赖、环境变量和可回退部署版本。

## 1. 依赖锁定

`requirements.txt` 全部使用精确版本（`==`），部署和本地测试使用同一套依赖：

```bash
python -m pip install -r requirements.txt
```

修改依赖后必须重新运行全量测试，并确认 `pip freeze` 与清单一致。

## 2. 环境变量清单

| 变量 | 必填 | 说明 |
|---|---|---|
| `MAP_REALTIME_API_KEY` | 云端时必填 | MiniCPM-o 云端 Realtime Key；走本地昇腾可留空 |
| `MAP_REALTIME_MODEL` / `MAP_REALTIME_BASE_URL` / `MAP_REALTIME_MAX_TOKENS` / `MAP_REALTIME_TIMEOUT` | 否 | 云端 MiniCPM-o Realtime 配置 |
| `ASCEND_OMNI_WS_URL` / `ASCEND_OMNI_TIMEOUT` | 否 | 昇腾本地后端地址与超时；配置后优先走本地 |
| `APP_LOCAL_AUDIO_CHUNK_SECONDS` / `APP_LOCAL_AUDIO_MAX_SECONDS` / `APP_LOCAL_TTS_ENABLED` | 否 | 本地昇腾音频分片与时长上限、本地 TTS 开关（默认 12s / 600s / 关闭；分片设 0 关闭） |
| `APP_MODEL_MODE` / `APP_ALLOW_EXTERNAL_MODELS` | 否 | 合规模式（minicpm / 0），参赛版本固定 |
| `STORAGE_BACKEND` | 否 | `local` 或 `s3`；生产建议 `s3` |
| `S3_BUCKET` | s3 时必填 | S3 兼容存储桶名 |
| `S3_PREFIX` | 否 | 对象存储前缀，默认 `workbench/` |
| `S3_REGION` | 否 | S3 区域，默认 `auto` |
| `S3_ENDPOINT_URL` | 否 | S3 兼容服务地址；留空使用云厂商默认 |
| `APP_HOST` / `APP_PORT` | 否 | 本地监听地址与端口 |
| `APP_ADMIN_TOKEN` | 否 | 站点管理令牌 |
| `APP_USERS_JSON` | 否 | 多用户账号文件路径 |
| `APP_NOTIFY_WEBHOOK` / `APP_NOTIFY_WEBHOOKS` | 否 | 群机器人 Webhook（企业微信 / 飞书 / 钉钉） |
| `APP_TZ_OFFSET` / `APP_TIMEZONE` | 否 | 应用时区，默认东八区 |

## 3. 发布前检查

```bash
python -m pytest tests/ -q
node --check app/web/static/app.js
node --check app/web/static/participants.js
python scripts/verify_media_models.py
```

`verify_media_models.py` 用于本地开发环境校验外部视觉/语音模型配置；参赛合规模式下无需配置这些模型，脚本返回 2 属于预期状态。

## 4. 部署记录

每次发布必须记录：

- 应用版本（FastAPI `/api/health` 和 `FullPlan.version`）
- Git commit hash
- 依赖锁定文件是否变更
- 环境变量是否新增/删除
- 真实模型验证结果（如适用）
- 全量测试数量与结果

## 5. 回退流程

1. 打开 Render 项目 Deploys 页面。
2. 选择上一份已验证部署，点击 `Rollback`。
3. 回退后访问 `/api/health`，确认版本号回退到预期值。
4. 执行一次核心链路验证：上传文件 → 生成草案 → 确认分工 → 导出。
5. 若回退涉及环境变量，先在 Render Environment 中恢复旧值，再触发部署。

本地回退：

```bash
git log --oneline -5
git checkout <上一已发布 commit>
python -m pip install -r requirements.txt
python -m pytest tests/ -q
```

## 6. 对象存储启用

把 `STORAGE_BACKEND` 改为 `s3`，并配置 `S3_BUCKET` 后，方案 JSON、
导出附件和分享令牌会在写入本地 memory 的同时同步到对象存储；本地文件缺失时
会自动从对象存储恢复。部署前建议用生命周期策略清理 `artifacts/` 前缀下超过
48 小时的导出附件。
