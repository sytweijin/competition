## 对我们最有用的结论

1. 创新应用赛道 Onboarding Checklist 指定 `llama.cpp-omni`，`vLLM-Omni` 属于推理优化赛道，不要混用。
2. 昇腾环境镜像选择 CANN；910C 上 llama.cpp 用 F16 最快，Q4_K_M 会退到 CPU。
3. A3 资源紧张、关机后难再开；多卡环境卡时按倍率消耗；卡时不足可申请补充。
4. VSCode SSH 不稳定时优先用 WebIDE；频繁 SSH 重连可能触发 IP 封禁（418）。
5. 910C + llama.cpp-omni 的 TTS 链路有已知 `aclnn_repeat_interleave` 算子报错；官方分支应可用，遇到问题找官方。
6. llama.cpp-omni 的视觉后端默认 `metal`，Linux/昇腾上文本和音频稳定，视觉输入仍需适配。
7. 官方免费 API `MiniCPM-o-4.5-Realtime` 可用于应用赛道，本地昇腾部署也可；两者官方都接受。
8. 应用赛道截止 8 月 31 日；评审看创新、实用、场景价值或趣味性，不拼推理性能。
9. Demo 公网访问：WebIDE 端口转发会随 WebIDE 关闭失效；Dev Tunnel / SSH 隧道 / VPS 可常驻。
10. MiniCPM-o 4.5 是 8B 模型，数学和强推理弱，演示避开高难度解题，突出全模态交互。
