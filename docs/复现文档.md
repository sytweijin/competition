| 项 | 版本/取值 |
|---|---|
| NPU | Ascend 910C（A3，`npu-smi info` Health OK） |
| 系统 | Ubuntu 22.04 容器（宿主机内核 openEuler 2203 SP4 aarch64） |
| CANN | 9.1.0-beta.1（`/usr/local/Ascend/cann-9.1.0-beta.1`） |
| Python | 3.12.13（A3）/ 3.11（应用侧） |
| 推理框架 | llama.cpp-omni（`-DGGML_CANN=ON -DLLAMA_OPENSSL=OFF`） |
| 模型权重 | `MiniCPM-o-4_5-F16.gguf`（~16GB，CANN 最快，勿用 Q4_K_M） |
| 应用 | FastAPI + 原生前端（无框架构建步骤） |

## 2. 模型与源码（A3 上）

```bash
# 模型目录结构（ModelScope 下载）
/workspace/MiniCPM-o-4_5-gguf/
├── MiniCPM-o-4_5-F16.gguf              # 主模型
├── audio/MiniCPM-o-4_5-audio-F16.gguf  # 音频编码器
├── vision/MiniCPM-o-4_5-vision-F16.gguf# 视觉编码器
├── tts/…                               # TTS（本地暂不使用）
└── token2wav-gguf/…                    # 声码器（本地暂不使用）

# 源码（国内代理 clone）
cd /workspace
git clone --depth 1 https://ghfast.top/https://github.com/tc-mb/llama.cpp-omni.git

# 编译
cd llama.cpp-omni
cmake -B build -DCMAKE_BUILD_TYPE=Release -DGGML_CANN=ON -DLLAMA_OPENSSL=OFF
cmake --build build --config Release -j --target llama-omni-server llama-omni-cli
```

## 3. 启动昇腾推理服务

```bash
cd /workspace/llama.cpp-omni
export LD_LIBRARY_PATH="$(pwd)/build/bin:${LD_LIBRARY_PATH}"
nohup ./build/bin/llama-omni-server \
  -m /workspace/MiniCPM-o-4_5-gguf/MiniCPM-o-4_5-F16.gguf \
  --host 0.0.0.0 --port 28099 -c 4096 -ngl 99 \
  > /tmp/llama-omni-server.log 2>&1 &

# 健康检查
curl http://127.0.0.1:28099/health
# 期望：{"engine":"comni","status":"ok"}
```

应用侧使用 `websockets` 库（requirements 已锁定 `websockets==16.1`），
连接本地昇腾后端时已禁用客户端 keepalive ping（`ping_interval=None`），
避免模型加载/推理慢时被默认 ping 超时主动断开（1011）；
`scripts/ascend_test_ws_*.py` 等独立冒烟脚本用 `websocket-client`。

## 7. 已知问题与规避

| 问题 | 规避 |
|---|---|
| 910C TTS 算子报错，会挂起单会话服务 | 本地后端不开 TTS；`/api/realtime/tts` 本地直接 501 |
| `vision_backend` 默认 metal | 视觉经 Realtime 图片消息验证可用；异常时联系官方 |
| 单活跃 session | WebSocket 与 HTTP 不混用；演示前预检暖机 |
| 磁盘平台回收 | 模型放 `/workspace/shared_assets` 共享，勿重复下载 |
| A3 关机后难开 | 提前申请卡时；开发用云端 API 并行 |
