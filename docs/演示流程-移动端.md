# 移动端演示流程

## 准备

1. 手机与演示环境处于同一公网可访问环境。
2. 打开清小搭移动端聊天入口。
3. 准备一张课程要求截图和一段短录音（建议不超过 30 秒）。

## 主流程

### 1. 读文件

- 从手机相册上传图片，从文件 App 上传 PDF 或音频。
- 观察回答是否附带逐文件状态提示；图片/音频未配置模型时应出现“需要确认”。

### 2. 做决策

- 输入项目人数、期限和交付物，例如“我们 3 个人 5 天完成一个调研报告”。
- 确认首屏先出现决策摘要，而不是一长串任务列表。

### 3. 发现风险

- 追问“健康度是多少”或“谁最忙”，验证回答来自同一份方案。

### 4. 应对变化

- 输入“如果截止日期提前 3 天，会怎样？”。
- 查看推演候选后回复“确认应用”。

### 5. 交付

- 点击工作台链接，在移动浏览器打开甘特图和导出按钮。
- 若移动端导出不便，改在桌面端继续，工作台链接不变。

## 移动端注意事项

- 首帧必须是 `assistant` role，不能先输出注释或 loading 文案。
- 用户提问气泡由平台展示，服务端不再回显“你问：”。
- 页面文本要能在窄屏换行，状态标签不应溢出按钮区域。

## 验收

- [ ] 手机上传图片/PDF/音频可返回状态；
- [ ] 首屏是决策摘要；
- [ ] 推演与确认应用在手机端可用；
- [ ] 工作台链接在手机浏览器可打开；
- [ ] 不出现“正在读取需求并生成分工与排期”的持久提示。
